## Контекст
Ведущему нужна кнопка в лобби, заполняющая все свободные места разнообразными ботами без ручного выбора стратегии. Сервер должен вычислять остаток мест атомарно, включая ограничения команд.

## Acceptance criteria
- [x] POST /session/{id}/npcs/random доступен только владельцу и возвращает состав сессии.
- [x] Свободные места заполняются разными случайно выбранными стратегиями с существующими параметрами по умолчанию.
- [x] Два параллельных запроса и повторное заполнение не превышают вместимость; запущенная игра отклоняется.
- [x] Поддержаны 120 игроков и нечётная вместимость двух команд.
- [x] Интеграционные тесты, check и генерация API-снимков успешны.

- [x] WebSocket сохраняет порядок публикации промежуточных и итогового составов.

## План
1. Проверить интеграционными тестами endpoint, владельца, вместимость и повторы.
2. Переиспользовать транзакционный bulk-сервис под блокировкой строки сессии.
3. Проверить backend и обновить API-контракт для frontend.
