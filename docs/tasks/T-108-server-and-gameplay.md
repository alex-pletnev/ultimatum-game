## Контекст
Пользователь переехал с прежнего облака, поручил временно разместить проект на текущем сервере и расширить продукт вместе с backend. Frontend T-026 содержит единый план.

## Acceptance criteria
- [x] Compose с отдельной постоянной PostgreSQL; HTTPS proxy и воспроизводимый redeploy.
- [x] Владение партией проверяется в серверных точках входа; PLAYER может вести свою партию.
- [x] Ведущий может играть, solo/rematch/history работают на реальных сущностях.
- [x] DICTATOR автоматически начисляет очки; старые режимы совместимы.
- [x] Конкурентные игровые действия сериализованы; start валидирует состав.
- [x] Unit, Detekt, coverage, PostgreSQL migration и E2E успешны.

## Лог
- 2026-10-23: согласования делегированы пользователем. Старую YC-выкладку не восстанавливаем. Выбран отдельный virtual host текущего Caddy и отдельные контейнеры проекта.

- 2026-10-23: реализованы владение командами REST/STOMP, участие ведущего, solo/rematch/mine, DICTATOR с Flyway V2 и блокировка игровых изменений. Существующие defaults API сохранены.
- Проверки: ./gradlew check generateApiSnapshots bootJar — успешно; 297 тестов, Detekt и порог покрытия пройдены. Негативные тесты чужого ADMIN охватывают все пять защищённых команд через Spring proxy; отдельные тесты запрещают чужие предложения и решения.
- 22 frontend Playwright на PostgreSQL прошли: одновременные ходы не теряются, счёт не дублируется; solо, команды, история, реванш, прерывание и восстановление.
- Выделенный Compose на текущем сервере здоров: API/web/db, постоянный database volume, restart unless-stopped. Миграции 1 и 2 успешны. По публичному HTTPS выполнены регистрация и три реальных раунда через WSS; CSV, история и UI проверены. Создан частный pg_dump после проверки.
- Внешний Caddy получил отдельный virtual host. Недоступный внешний DNS у прокси обойдён резервным resolver с сохранением Docker DNS; локальные инструкции отмечают необходимость сохранить настройку при пересоздании общего прокси. Ключ JWT исправлен на стандартный Base64 до рабочего входа. Секреты, адреса и эксплуатационные заметки находятся вне Git.
- Независимое ревью не выявило блокирующих ошибок. Старый YC Release не запускался, старая облачная БД не импортирована. Существующий шум Springwolf scanner (T-099) не влияет на игру и остаётся отдельной задачей.
