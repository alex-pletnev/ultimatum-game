## Контекст
Фидбек после живой игры с 20 участниками: потеря входа, ошибки раунда/создания,
блокировка при отключении, анонимность, 2–4 команды, точный ввод и аналитика.
Пользователь поручил самостоятельно принять решения, реализовать и опубликовать
по существующему адресу. Связанная задача: frontend T-028.

## Acceptance criteria
- [x] Истёкший access JWT даёт 401; refresh восстанавливает того же игрока/ведущего.
- [x] Временный сетевой сбой/5xx/отказ игрового действия не удаляет авторизацию.
- [x] Восстановление по секретному коду возвращает профиль, игры и права; публичный ID не даёт вход.
- [x] Ведущий включает/отключает автопилот 50/50 для участника; нет повторных ходов/очков.
- [x] Автоматические действия отмечены в истории и CSV отдельно от человеческих.
- [x] Анонимность настраивается при создании; личности контрагентов скрыты в REST/WS и аналитике.
- [x] Создание/вступление/боты/игра/реванш работают с 2, 3, 4 командами.
- [x] Сумму можно вводить цифрами и менять на 1, сохраняя ползунок и валидацию.
- [x] Итог виден первым; графики предложений, принятий/отказов и показатели по командам.
- [x] Регрессионные unit/integration, полный check, frontend lint/build/test и Playwright успешны.
- [x] Backup, публикация на прежний HTTPS, проверка 20 участников и desktop/mobile.

## Решения и охват
- Существующий Kotlin/Spring/PostgreSQL + React стек; без новых зависимостей.
- Вход по случайному секретному коду, хранимому на сервере в виде хеша. Не по публичному нику/UUID.
- Автопилот включает ведущий явно; предлагает половину, принимает не меньше половины.
  Возврат человека сохраняет уже сделанные ходы; автопилот можно выключить.
- Анонимность по умолчанию для новых игр: стабильные псевдонимы внутри партии,
  реальные имена видны в списке участников ведущему, но не связываются с решениями публично.
- Команды 2–4 с существующим межкомандным подбором; итог, средние предложения,
  принятия/отказы, результаты команд; специальные исследовательские отчёты после нового фидбека.
- Карта: auth filter/service/controller/DTO/User + client/storage/STOMP/Register/AppShell;
  SessionConfig/migration/mappers/create/rematch; NpcService/SessionScenarios + Session;
  EventPublisher/round DTO/history/statistics/CSV; CreateSession/SessionJoin/Stats/Guide;
  контракты, unit/integration/E2E и deployment.
